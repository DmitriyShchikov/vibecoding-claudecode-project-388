# Трекер цен с Claude


[![hexlet-check](https://github.com/DmitriyShchikov/vibecoding-claudecode-project-388/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/DmitriyShchikov/vibecoding-claudecode-project-388/actions)

Трекер цен, собранный на скиллах Claude Code: следит за списком товаров в
интернет-магазинах, снимает цены и складывает каждый прогон в отдельный
репозиторий-историю.

Учебный проект Хекслета: https://ru.hexlet.io/programs/vibecoding-claudecode


## Как это устроено

Логика живёт не в приложении, а в скиллах — папках с `SKILL.md`, которые Claude
Code подгружает сам, когда задача совпадает с их описанием.

```
запрос «проверь цены»
        │
        ▼
   tracker ──────────► extract-price ──────► магазин
   обход списка        цена с одной          (HTML или API)
   и таблица           страницы
        │
        ▼
  GitHub MCP ────────► tracker-data/YYYY-MM-DD.json
  (запись = коммит)    история прогонов
```

| Скилл | Что делает |
|---|---|
| [`extract-price`](.claude/skills/extract-price/SKILL.md) | снимает цену с одной страницы по URL |
| [`tracker`](.claude/skills/tracker/SKILL.md) | обходит список URL, собирает таблицу, коммитит её в историю |

`tracker` переиспользует `extract-price`, а не дублирует его: вся работа со
страницами — адаптеры под магазины, кодировки, распознавание антибота — лежит в
одном месте. Новый магазин добавляется только в `extract-price` и сразу работает
в обходе.

### Контракт цены

`extract-price` возвращает объект из трёх полей — на нём держится всё остальное:

```json
{"regular_price": 54099.0, "sale_price": 40374.0, "has_credit": true}
```

- `regular_price` — обычная цена, заполнена всегда;
- `sale_price` — цена по скидке; `null`, если скидки нет;
- `has_credit` — рассрочка: `true` / `false`, либо `null`, если источник такого
  признака не отдаёт.

### Поддерживаемые магазины

| Магазин | Как берётся цена |
|---|---|
| Wildberries | публичный JSON `card.wb.ru` — карточка закрыта антиботом |
| holodilnik.ru | микроразметка schema.org, страницы в windows-1251 |
| regard.ru | JSON-LD `Product` |
| остальные | общий разбор schema.org, если сайт размечен |

Крупные федеральные ритейлеры (Ozon, DNS, М.Видео, Ситилинк, Эльдорадо,
onlinetrade и другие) закрыты антиботом и капчей. Обход защиты в проекте не
делается — вместо этого добавляется другой источник.

## Использование

### Через Claude

```
проверь цены
```

Claude сам вызовет `tracker`: обойдёт список, покажет таблицу и закоммитит
прогон в историю.

```
сколько стоит https://www.wildberries.ru/catalog/899301731/detail.aspx
```

Это одна страница — сработает `extract-price`.

### Напрямую из терминала

```bash
# одна страница
python3 .claude/skills/extract-price/scripts/extract_price.py <URL>
# {"regular_price": 54099.0, "sale_price": 40374.0, "has_credit": true}

# весь список
python3 .claude/skills/tracker/scripts/tracker.py
```

```
url                                                        regular_price   sale_price  has_credit
-------------------------------------------------------------------------------------------------
https://www.wildberries.ru/catalog/899301731/detail.aspx        65 750 ₽     10 546 ₽         н/д
https://www.wildberries.ru/catalog/200608562/detail.aspx       124 536 ₽     94 896 ₽         н/д
-------------------------------------------------------------------------------------------------
строк: 10 | собрано: 10 | со скидкой: 10 | ошибок: 0 | 2026-09-07T15:31:53+00:00
```

Форматы: `--json`, `--csv`, `--full` (добавляет название, скидку, наличие,
время), `--save <каталог>` (файл прогона для публикации).

### Список отслеживаемых товаров

Зашит в константе `TRACKED_URLS` в начале
[`.claude/skills/tracker/scripts/tracker.py`](.claude/skills/tracker/scripts/tracker.py).
Чтобы добавить или убрать товар, правится этот список; дубликаты отбрасываются
при обходе.

## История прогонов

Один прогон — один файл `YYYY-MM-DD.json` в корне репозитория
[`tracker-data`](https://github.com/DmitriyShchikov/tracker-data). Внутри —
таблица прогона: объект на товар с полями `url`, `regular_price`, `sale_price`,
`has_credit`, `error`.

Файл пишется через GitHub MCP, а запись через MCP — это сразу отдельный коммит:
репозиторий истории не клонируется, локальных `git commit` и `git push` нет.
Повторный прогон за ту же дату перезаписывает файл, прежний остаётся в истории
коммитов.

## Чего пока нет

- **Сравнения прогонов.** Файлы копятся, но никто не говорит, что подешевело, —
  это следующий скилл.
- **Уведомлений в Telegram.** Появятся, когда будет с чем сравнивать: слать
  каждый прогон целиком бессмысленно.
- **Запуска по расписанию.** Сейчас обход стартует вручную.

Отдельно стоит помнить, что `regular_price` на Wildberries — витринный якорь
(встречается «450 000 ₽ → 17 145 ₽»), а не история цены. Реальную динамику даст
только сравнение собственных прогонов.
