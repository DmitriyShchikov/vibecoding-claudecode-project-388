# Извлечение цены по URL

## Контракт

**Вход:** один URL страницы товара.

**Выход:** объект из трёх полей.

| Поле | Тип | Значение |
|---|---|---|
| `regular_price` | число | обычная цена (без скидки) |
| `sale_price` | число или `null` | цена по скидке; `null`, если скидки нет |
| `has_credit` | `true` / `false` / `null` | доступна ли рассрочка; `null` — источник не сообщает |

```json
{"regular_price": 54099.0, "sale_price": 40374.0, "has_credit": true}
```

Правила, которых обязан придерживаться любой адаптер:

- `regular_price` — всегда заполнен. Если цены на странице нет, это ошибка, а не
  `null`.
- `sale_price` заполняется, **только когда он строго меньше** `regular_price`.
  Товар без скидки даёт `null`, а не дублирование обычной цены.
- `has_credit` — `null` вместо `false`, когда источник не отдаёт этот признак.
  `false` означает «проверено, рассрочки нет».

Одна страница — один объект. Скилл ничего не сохраняет: хранение истории и
сравнение — задача других скиллов.

## Когда применять

- «сколько стоит <ссылка>», «проверь цену вот тут», «вытащи цену со страницы»;
- нужно снять текущее значение перед записью в историю цен;
- проверка, поддерживается ли новый магазин.

Не применять для обхода списка товаров по расписанию — это `check-prices`.

## Быстрый старт

```bash
python3 .claude/skills/extract-price/scripts/extract_price.py <URL>
```

Зависимости: `pip install -r requirements.txt` (`requests`, `selectolax`).

Вывод:

```json
{
  "regular_price": 54099.0,
  "sale_price": 40374.0,
  "has_credit": true
}
```

Флаги: `--raw` — JSON одной строкой (для пайпов), `--dest <код>` — регион
Wildberries (по умолчанию Москва, `-1257786`), `--full` — добавить к контракту
контекст (`name`, `availability`, `stock`, `region`, `checked_at`) для записи в
историю. Контракт при `--full` не меняется, поля только добавляются.

Коды возврата: `0` — цена найдена; `1` — источник ответил, но цены нет
(товар снят с продажи либо сайт не размечен); `2` — сеть, антибот или API
недоступен. Разделение важно для трекера: `2` — временная ошибка, повторить
позже; `1` — постоянная, повторять бессмысленно, нужен адаптер или снятие
товара с отслеживания.

## Порядок действий

1. Проверить URL: должен быть `http(s)` и вести на карточку товара, а не на
   категорию или поиск.
2. Запустить скрипт. При успехе показать пользователю название, цену и наличие.
3. При коде `1` — посмотреть, есть ли на странице разметка schema.org, и решить,
   писать ли адаптер (см. ниже).
4. При коде `2` — сообщить причину. Если это антибот, не пытаться его обойти:
   предложить другой источник или ручной ввод цены.
5. При коде `1` на Wildberries — проверить артикул: товар мог быть снят с продажи.

## Поддерживаемые источники

| Домен | `regular_price` | `sale_price` | `has_credit` |
|---|---|---|---|
| `wildberries.ru` | `price.basic` ÷ 100 | `price.product` ÷ 100 | `null` — в API признака нет, карточка закрыта антиботом |
| `holodilnik.ru` | `.product-price__old`, иначе `.product-price__current` | `.product-price__current`, если есть зачёркнутая | наличие блока `.credit_cont` («Купить в рассрочку») |
| `regard.ru` | `offers.price` из JSON-LD | `null` — скидки в разметке не размечены | флаги `"credit"/"installment": {"enabled", "from", "to"}` с проверкой попадания цены в лимиты |
| любой другой | `offers.price` или `meta[itemprop="price"]` | `null` | `null` |

Данные Wildberries берутся не со страницы, а из публичного JSON фронтенда
`card.wb.ru/cards/v4/detail` — сама карточка закрыта антиботом.

## Грабли, на которые уже наступали

- **Цены Wildberries приходят в копейках.** `price.product = 1054600` — это
  10 546 ₽. Делить на 100.
- **У WB цена зависит от региона.** Одна карточка: Москва 10 546 ₽,
  Санкт-Петербург 10 388 ₽. Поэтому `region` попадает в результат — сравнивать
  цены между разными `dest` нельзя, будут ложные срабатывания.
- **WB версионирует API без предупреждения.** `v1`–`v3` уже отдают 404, живёт
  `v4`. Скрипт перебирает версии по порядку; если однажды отвалятся все —
  открыть карточку в браузере и посмотреть в DevTools, какой эндпоинт зовёт сайт.
- **`regular_price` на WB — маркетинг, а не история.** Встречается
  «450 000 ₽ → 17 145 ₽». Для отслеживания динамики брать `sale_price` (а при
  `null` — `regular_price`) и сравнивать со своей записанной историей, а не с
  тем, что показывает сайт.
- **`has_credit` нельзя искать текстом по странице.** Слова «рассрочка» и
  «кредит» есть в мета-описании и в словарях интерфейса на каждой странице —
  поиск по тексту даст `true` всегда. Нужен признак, привязанный к товару:
  проверено, что на позиции за 229 ₽ блок `.credit_cont` отсутствует, а на
  позиции за 40 374 ₽ присутствует.
- **Кодировка страницы бывает не UTF-8.** holodilnik.ru отдаёт windows-1251;
  без явного декодирования получится мусор вместо кириллицы.
- **В каталоге две цены в одном блоке.** Текущая и зачёркнутая склеиваются в
  «4 037 454 099 ₽», если брать текст всего блока. Нужен точный селектор
  (`.price-value__actual`), а не `.price-value`.
- **Пустой результат ≠ отсутствие товара.** Страница-заглушка антибота
  выглядит как обычный HTML без цены. Скрипт ловит это по маркерам
  (`js-challenge`, `servicepipe`, `__wbaas`, `sp_rotated_captcha`, `qrator`) и
  возвращает код `2`.

## Ссылки Wildberries

Канонический вид — `https://www.wildberries.ru/catalog/<nm>/detail.aspx`, без
параметров сессии. Хранить и дедуплицировать товары нужно по `nm`, а не по URL:
из артикула ссылка собирается тривиально, а разбор URL даёт тот же `nm` при
любых мусорных `?utm_source=...`.

## Магазины, закрытые антиботом

`onlinetrade.ru` (ServicePipe + капча), `dns-shop.ru` (401), `citilink.ru` (429),
`eldorado.ru` (503), `mvideo.ru`, `sportmaster.ru` (401), `vseinstrumenti.ru`
(403), `technopark.ru` (503), `lamoda.ru`, `megamarket.ru`, `market.yandex.ru`,
`ozon.ru`. Обходить защиту не нужно и не следует — предлагать другой источник.

## Как добавить новый магазин

1. Проверить, отдаётся ли страница без антибота:
   ```bash
   curl -sS -A "Mozilla/5.0" "<URL>" | head -c 500
   ```
2. Поискать готовую разметку — часто адаптер вообще не нужен:
   ```bash
   curl -sS -A "Mozilla/5.0" "<URL>" | grep -o 'application/ld+json' | head -1
   curl -sS -A "Mozilla/5.0" "<URL>" | grep -o 'itemprop="price"[^>]*' | head -3
   ```
3. Если разметки нет — дописать функцию-адаптер в `scripts/extract_price.py`
   и зарегистрировать домен в кортеже `ADAPTERS`. Адаптер обязан вернуть
   контракт через хелпер `contract(regular, sale, has_credit)` — он же следит,
   чтобы `sale_price` не оказался больше или равен `regular_price`.
4. Проверить минимум на четырёх карточках: со скидкой и без неё, с рассрочкой
   и без. Товар без скидки обязан дать `sale_price: null`, а не копию обычной
   цены; если `has_credit` выходит одинаковым на всех товарах — признак выбран
   неверно.
