# Новый скилл проекта

Заводит папку скилла в `.claude/skills/` так, чтобы Claude Code гарантированно
подхватил её при следующем старте сессии.

## Когда применять

- «добавь скилл X», «заведи новый скилл», «сделай скилл для проверки цен»;
- вопрос о том, как правильно оформить `SKILL.md` или его фронтматтер;
- скилл не подхватывается и надо проверить структуру.

## Порядок действий

1. Уточнить у пользователя имя в kebab-case и одну фразу о том, что скилл делает
   и когда его применять. Если имя очевидно из запроса — не переспрашивать.
2. Проверить, что папки ещё нет:
   ```bash
   ls .claude/skills/
   ```
3. Создать скилл из шаблона:
   ```bash
   mkdir -p .claude/skills/<имя>
   cp .claude/skills/new-skill/references/TEMPLATE.md .claude/skills/<имя>/SKILL.md
   ```
4. Заполнить в `SKILL.md` фронтматтер (`name` — строго равен имени папки) и тело:
   когда применять, входные данные, шаги, формат результата, крайние случаи.
   Удалить из шаблона разделы, которые скиллу не нужны.
5. Проверить структуру (см. ниже) и сказать пользователю, что скилл появится
   после перезапуска сессии Claude Code.

## Проверка

```bash
python3 .claude/skills/new-skill/scripts/check_skills.py
```

Скрипт проходит по `.claude/skills/*/SKILL.md`, проверяет наличие фронтматтера,
полей `name` и `description` и совпадение `name` с именем папки.

## Правила, из-за которых скилл не подхватывается

- Скилл — это **папка** с файлом `SKILL.md`. Отдельный `.md`-файл в
  `.claude/skills/` не загружается (поэтому шаблон лежит в `references/`).
- Имя файла ровно `SKILL.md`, регистр важен.
- Фронтматтер — первым в файле, между строками `---`, с полями `name` и
  `description`.
- `name` — только строчные латинские буквы, цифры и дефисы, совпадает с именем папки.
- Скиллы читаются при старте сессии: после добавления нужен перезапуск.

## Что писать в description

Это единственное, что Claude видит до загрузки скилла. Нужны и «что делает», и
«когда применять», со словами, которыми пользователь реально формулирует задачу.
Плохо: «Работа с ценами». Хорошо: «Собирает текущие цены по списку товаров.
Использовать, когда просят проверить цены, обновить прайс или запустить обход
товаров».

## Полезные файлы

- `references/TEMPLATE.md` — шаблон `SKILL.md` для копирования.
- `scripts/check_skills.py` — валидатор структуры скиллов.
- `.claude/skills/README.md` — соглашения проекта и план скиллов трекера.
