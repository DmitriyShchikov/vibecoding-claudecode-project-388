# Скиллы проекта

Здесь живут скиллы Claude Code для трекера цен. Скилл — это **папка** с файлом
`SKILL.md`, которую Claude подгружает сам, когда задача совпадает с описанием
из `description`.

## Структура

```
.claude/skills/
├── README.md                  # этот файл (скиллом не является)
└── new-skill/                 # скилл: заводит новые скиллы по шаблону
    ├── SKILL.md               # обязательный файл: фронтматтер + инструкции
    ├── references/
    │   └── TEMPLATE.md        # шаблон SKILL.md для копирования
    └── scripts/
        └── check_skills.py    # валидатор структуры скиллов
```

Загружаются только папки с `SKILL.md` внутри. Одиночные `.md`-файлы прямо в
`.claude/skills/` игнорируются — поэтому шаблон лежит в `references/`, а не рядом
с README.

## Как добавить скилл

Проще всего попросить Claude: «заведи скилл check-prices» — сработает скилл
`new-skill`. Вручную:

```bash
mkdir -p .claude/skills/my-skill
cp .claude/skills/new-skill/references/TEMPLATE.md .claude/skills/my-skill/SKILL.md
# заполнить фронтматтер и тело
python3 .claude/skills/new-skill/scripts/check_skills.py
```

Скиллы читаются при старте сессии — после добавления перезапустить Claude Code
и проверить, что скилл виден (`/my-skill` или запрос, попадающий под
`description`).

## Фронтматтер

```yaml
---
name: my-skill              # только строчные буквы, цифры и дефисы; совпадает с именем папки
description: >-             # 1–3 предложения: ЧТО делает и КОГДА применять
  Что делает скилл. Использовать, когда пользователь просит X, упоминает Y
  или работает с Z.
---
```

`description` — единственное, что Claude видит до загрузки скилла, поэтому в нём
должны быть слова-триггеры, которыми пользователь реально формулирует задачу.

## Если скилл не подхватился

1. `python3 .claude/skills/new-skill/scripts/check_skills.py` — покажет ошибки
   структуры.
2. Файл называется ровно `SKILL.md` (регистр важен) и лежит внутри папки скилла.
3. Фронтматтер идёт первым в файле, между строками `---`, с полями `name` и
   `description`; `name` совпадает с именем папки.
4. Сессия перезапущена после добавления файла.

## Соглашения

- Одна задача — один скилл; не складывать в скилл всё подряд.
- `SKILL.md` держать компактным (ориентир — до ~500 строк), длинные справочники
  выносить в `references/` и ссылаться на них из тела.
- Инструкции писать императивно и по шагам, с примерами команд.
- Имена в kebab-case: `track-prices`, а не `TrackPrices`.
