# Скиллы проекта

Здесь живут скиллы Claude Code для трекера цен. Скилл — это **папка** с файлом
`SKILL.md`, которую Claude подгружает сам, когда задача совпадает с описанием
из `description`.

## Структура

```
.claude/skills/
├── README.md              # этот файл (скиллом не является)
├── extract-price/         # скилл: извлечение цены товара по URL
│   ├── SKILL.md           # обязательный файл: фронтматтер + инструкции
│   └── scripts/
│       └── extract_price.py
└── tracker/               # скилл: обход списка URL и таблица цен
    ├── SKILL.md
    └── scripts/
        └── tracker.py
```

Загружаются только папки с `SKILL.md` внутри. Одиночные `.md`-файлы прямо в
`.claude/skills/` игнорируются.

## Как добавить скилл

```bash
mkdir -p .claude/skills/my-skill
$EDITOR .claude/skills/my-skill/SKILL.md
```

Минимальный `SKILL.md`:

```markdown
---
name: my-skill
description: >-
  Что делает скилл. Использовать, когда пользователь просит X, упоминает Y
  или работает с Z.
---

# My Skill

## Когда применять
- ...

## Порядок действий
1. ...
```

Скиллы читаются при старте сессии — после добавления перезапустить Claude Code
и проверить, что скилл виден (`/my-skill` или запрос, попадающий под
`description`).

## Фронтматтер

- `name` — только строчные латинские буквы, цифры и дефисы; строго совпадает с
  именем папки.
- `description` — 1–3 предложения: что делает и когда применять. Это
  единственное, что Claude видит до загрузки скилла, поэтому нужны слова, которыми
  пользователь реально формулирует задачу. Плохо: «Работа с ценами». Хорошо:
  «Извлекает цену товара по URL. Использовать, когда дают ссылку на товар и
  просят узнать цену».

## Если скилл не подхватился

1. Файл называется ровно `SKILL.md` (регистр важен) и лежит внутри папки скилла,
   а не рядом с этим README.
2. Фронтматтер идёт первым в файле, между строками `---`, с полями `name` и
   `description`.
3. `name` совпадает с именем папки и написан в kebab-case.
4. Сессия перезапущена после добавления файла.

## Соглашения

- Одна задача — один скилл; не складывать в скилл всё подряд.
- `SKILL.md` держать компактным (ориентир — до ~500 строк), длинные справочники
  выносить в `references/` и ссылаться на них из тела.
- Инструкции писать императивно и по шагам, с примерами команд.
- Имена в kebab-case: `extract-price`, а не `ExtractPrice`.
